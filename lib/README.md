# lib/

The MySQL JDBC driver is already here (`mysql-connector-j-*.jar`).

If you ever need a fresh copy:
1. Download **mysql-connector-j** (Platform Independent ZIP) from
   <https://dev.mysql.com/downloads/connector/j/>
2. Unzip it and copy `mysql-connector-j-x.y.z.jar` into this folder.

In IntelliJ: File → Project Structure → Modules → Dependencies → + (JARs) →
select the jar. Then run `Main`.
